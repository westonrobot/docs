# Support

Everything here is for when something is wrong, or when you need to reach us.

If you are looking for how to *do* something — operate safely, maintain the robot, set up CAN, run SLAM — that is under [Guides](/tutorial/intro).

## Start here

| If you… | Go to |
| --- | --- |
| are about to raise a ticket | [Before you contact us](/support/before-you-contact-us) — collect this first and we can usually answer in one reply |
| need your serial number or model | [Identify your product](/support/identify-your-product) |
| have a question that might be common | [FAQ](/support/faq) |
| are seeing an error or fault code | [Fault codes](/support/fault-codes) |
| need a repair, replacement or return | [Warranty and RMA](/support/warranty-and-rma) |

## Contact us

Submit a request through our [support form](https://forms.office.com/r/qELKzYF33W).

Please read [Before you contact us](/support/before-you-contact-us) first. Tickets that arrive with the serial number, firmware version and a description of what changed are usually resolved in a single exchange; tickets without them take several.

## Older products

Documentation for products that predate this site is at [docs-legacy](https://westonrobot.github.io/docs-legacy/).
