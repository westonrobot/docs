# reComputer Industrial J4012

<Split ratio="wide-narrow">

<div>

The reComputer Industrial J4012 is Seeed Studio's industrial edge AI computer, built on the **NVIDIA Jetson Orin NX 16GB**. It is the option to fit when the workload is perception or autonomy and needs a GPU — mapping, object detection, or anything running a neural network on-robot.

It is fanless, cooled by a passive heatsink, and enclosed, which is what makes it usable on a robot rather than on a bench.

This page does not repeat or replace Seeed Studio's documentation. It covers what you need to fit the unit to a robot and reach its interfaces; Seeed document the board itself.

## Fitting it

| | |
| --- | --- |
| **Power input** | DC 12–24 V, terminal block |
| **Operating temperature** | −20 °C to 60 °C, with 0.7 m/s airflow |
| **Dimensions** | 159 × 155 × 57 mm |
| **Weight** | 1.57 kg |
| **Mounting** | Desk, DIN rail, wall, VESA |

Two points that matter when you are planning an installation:

- **The airflow figure is a condition, not a footnote.** The J4012 is fanless, so its temperature rating assumes 0.7 m/s of moving air across the heatsink. Sealed inside an unventilated enclosure it will throttle under sustained GPU load.
- **At 1.57 kg it is heavy for a payload.** Account for it in the mass budget, and mount it to structure rather than to a panel.

One Ethernet port supplies **PoE (802.3af PSE)**, so a PoE camera or sensor can be powered from the computer rather than needing its own supply — subject to the platform's overall power budget.

| Camera | 2 × CSI (2-lane, 15-pin) | |
| Serial | 1 × RS-232 / RS-422 / RS-485 | Configurable — set the mode before wiring |

If you are connecting the computer to a robot base over CAN, note the single interface: a platform that needs one CAN bus for the base and another for a sensor will not fit on this unit without an adapter.

## Troubleshooting & FAQ

### The unit throttles under sustained load

It is passively cooled and rated with 0.7 m/s of airflow. Check that the installation actually provides it — see [Fitting it](#fitting-it).

### The Type-C port will not talk to a USB device

It is a device-mode port, not a host port. Use one of the three USB 3.2 Type-A ports instead.

For fault and alarm codes, see [Fault codes](/support/fault-codes). General questions are answered on the [Support FAQ](/support/faq).
