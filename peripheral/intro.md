# Peripherals

Components that mount on, or connect to, a robot platform — onboard computers, networking, power and sensors. Each has been tested for compatibility with our platforms.

## Onboard computers

| Computer | Use it when |
| --- | --- |
| [NanoPC](/peripheral/computer/nanopc) | Compact ARM board for lighter workloads |
| [CM4-based computer](/peripheral/computer/cm4) | Raspberry Pi CM4 form factor |
| [Jetson Orin NX J4012](/peripheral/computer/j4012) | GPU compute for perception and autonomy |

## Networking

| Device | Use it when |
| --- | --- |
| [Industrial 5G / WiFi router](/peripheral/network/industrial_5g_router) | The robot needs cellular or WiFi connectivity in the field |

## Power

| Device | Use it when |
| --- | --- |
| [Power Regulator v2.X](/peripheral/power/power_regulator_v2) | You need switchable, regulated output rails for payloads |

## Sensors

| Sensor | Use it when |
| --- | --- |
| [Manifold Pocket Scanner](/peripheral/sensor/manifold_pocket) | Handheld scanning alongside a robot deployment |
