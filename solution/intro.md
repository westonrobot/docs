# Solutions

A solution is a complete capability we develop and deploy on top of a robot platform, rather than a component you integrate yourself. Each one runs on a defined set of platforms and comes with its own deployment, configuration and release notes.

If you are looking for the robot itself, see [Robots](/robot/intro). If you are looking for a task guide, see [Guides](/tutorial/intro).

## Available now

### [Assisted Driving Toolbox](/solution/adt/intro)

Teleoperation for mobile robot platforms — remote control and operation over a shared network, with camera coverage of the robot's surroundings. Three versions are in service; see the version pages for what changed and which applies to your deployment.

## In development

**Navigation** and **Industrial Patrolling** are in development. Documentation for each will appear here as it becomes available, and pilot customers will be given direct links ahead of general release.
